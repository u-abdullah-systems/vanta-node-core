SYS // SYSTEM OVERVIEW

VANTA NODE is a realtime multiplayer systems sandbox. The Node.js server owns simulation state; the browser client is a replica that sends intent and renders authoritative snapshots.

Server NODE.JS

  • 20 Hz simulation tick with change-gated PARK_STATE broadcasts
  • Authoritative movement, cargo, goals and activity state
  • JWT HS512 session tokens; ephemeral secret by default
  • WS gateway for realtime, REST /api/health for telemetry
  • Flood control, heartbeat pruning and chat moderation pipeline

Client VANILLA JS

  • Canvas 2D renderer with no external art or audio assets
  • Interpolated remote actors; input is intent, not truth
  • 60 fps rAF render loop with throttled HUD updates
  • Client-computed STATE rate, RTT and heap telemetry
  • Deterministic pixel operator sprites and procedural props

Operations CO-OP

  • Sync Sequence — hold three nodes under load
  • Signal Transfer — pass the trace, 2+ operators
  • Motion Sync Drill — emote cadence scoring
  • Data Recovery — recover six fragments
  • Solo field test is playable; co-op unlocks at 2+
